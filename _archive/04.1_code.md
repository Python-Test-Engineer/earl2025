Certainly! Below is a Python implementation that uses the Pandas library to impute missing values in a DataFrame with the mean of each column:

```python
import pandas as pd
import numpy as np

# Creating a sample DataFrame for demonstration
data = {
    'A': [1, 2, np.nan, 4],
    'B': [np.nan, 2, 3, 4],
    'C': [1, np.nan, np.nan, 4]
}

df = pd.DataFrame(data)

# Display the original DataFrame
print("Original DataFrame:")
print(df)

# Function to impute missing values with the column mean
def impute_missing_with_mean(dataframe):
    return dataframe.fillna(dataframe.mean())

# Impute missing values
df_imputed = impute_missing_with_mean(df)

# Display the DataFrame after imputation
print("\nDataFrame After Imputation:")
print(df_imputed)
```

### Explanation:
1. We import the necessary libraries: `pandas` for data manipulation and `numpy` for handling NaN values.
2. We create a sample DataFrame `df` that includes missing values (represented by `np.nan`).
3. The function `impute_missing_with_mean` takes a DataFrame as input and fills missing values with the mean of each column using the `fillna()` method.
4. Finally, we display the original and imputed DataFrames.
