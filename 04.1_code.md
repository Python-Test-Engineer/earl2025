**Imputing Missing Values in a Pandas DataFrame with Mean**
===========================================================

The following Python code snippet demonstrates how to impute missing values in a Pandas DataFrame with the mean of the respective column.

```python
# Import the necessary libraries
import pandas as pd
import numpy as np

def impute_missing_values_with_mean(df):
    """
    Impute missing values in a Pandas DataFrame with the mean of the column.

    Args:
    - df (pd.DataFrame): The input DataFrame.

    Returns:
    - df_imputed (pd.DataFrame): The DataFrame with missing values imputed.
    """
    # Create a copy of the original DataFrame to avoid modifying it
    df_imputed = df.copy()

    # Iterate over each column in the DataFrame
    for col in df_imputed.columns:
        # Check if the column contains missing values
        if df_imputed[col].isnull().any():
            # Calculate the mean of the column, excluding missing values
            mean_val = df_imputed[col].mean(skipna=True)
            
            # Replace missing values in the column with the mean value
            df_imputed[col] = df_imputed[col].fillna(mean_val)

    return df_imputed

# Example usage
if __name__ == "__main__":
    # Create a sample DataFrame with missing values
    data = {
        'A': [1, 2, np.nan, 4, 5],
        'B': [np.nan, 2, 3, 4, 5],
        'C': [1, 2, 3, 4, np.nan]
    }
    df = pd.DataFrame(data)

    print("Original DataFrame:")
    print(df)

    # Impute missing values with the mean of the column
    df_imputed = impute_missing_values_with_mean(df)

    print("\nDataFrame with missing values imputed:")
    print(df_imputed)
```

**Explanation**
---------------

This code defines a function `impute_missing_values_with_mean` that takes a Pandas DataFrame as input and returns a new DataFrame with missing values imputed using the mean of the respective column.

1.  **Import Libraries**: The code starts by importing the necessary libraries, including `pandas` for data manipulation and `numpy` for numerical operations.
2.  **Function Definition**: The `impute_missing_values_with_mean` function is defined, which takes a Pandas DataFrame `df` as input.
3.  **Create a Copy**: A copy of the original DataFrame is created using the `copy` method to avoid modifying the original data.
4.  **Iterate Over Columns**: The code iterates over each column in the DataFrame using a `for` loop.
5.  **Check for Missing Values**: For each column, it checks if there are any missing values using the `isnull` method with the `any` method.
6.  **Calculate Mean**: If missing values are found, the mean of the column is calculated using the `mean` method with the `skipna=True` argument to exclude missing values.
7.  **Impute Missing Values**: The missing values in the column are replaced with the calculated mean value using the `fillna` method.
8.  **Return Imputed DataFrame**: Finally, the function returns the DataFrame with missing values imputed.
