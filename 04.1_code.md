```python
import pandas as pd
import numpy as np

def impute_missing_values(df):
    """
    Imputes missing values in the DataFrame with the mean of each column.
    
    Parameters:
    df (pd.DataFrame): The DataFrame with potential missing values.
    
    Returns:
    pd.DataFrame: A new DataFrame with missing values imputed.
    """
    # Calculate the mean for each column
    means = df.mean()
    
    # Impute missing values with the mean
    imputed_df = df.fillna(means)
    
    return imputed_df

# Example usage:
if __name__ == "__main__":
    # Creating a sample DataFrame with missing values
    data = {
        'A': [1, 2, np.nan, 4],
        'B': [np.nan, 5, 6, 7],
        'C': [9, 10, np.nan, 12]
    }
    
    df = pd.DataFrame(data)
    print("Original DataFrame:")
    print(df)
    
    # Impute missing values
    imputed_df = impute_missing_values(df)
    print("\nDataFrame after imputing missing values:")
    print(imputed_df)
```

### Explanation:
- The function `impute_missing_values` takes a Pandas DataFrame as input and computes the mean of each column using `df.mean()`.
- It then uses the `fillna()` method to replace missing values with the corresponding column means.
- The example at the bottom creates a sample DataFrame, displays the original DataFrame, and then shows the DataFrame after imputation.
