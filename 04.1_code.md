```python
import pandas as pd
import numpy as np

def impute_missing_values_with_mean(df):
    """
    Imputes missing values in a DataFrame with the mean of each column.
    
    Parameters:
    df (pd.DataFrame): The input DataFrame with possible missing values.
    
    Returns:
    pd.DataFrame: A new DataFrame where missing values are replaced with column means.
    """
    # Ensure input is a DataFrame
    if not isinstance(df, pd.DataFrame):
        raise ValueError("Input must be a pandas DataFrame.")

    # Create a copy of the DataFrame to avoid modifying the original
    df_imputed = df.copy()

    # Impute missing values with the column means
    for column in df_imputed.columns:
        if df_imputed[column].isnull().any():  # Check if there are missing values
            mean_value = df_imputed[column].mean()  # Calculate the mean
            df_imputed[column].fillna(mean_value, inplace=True)  # Impute missing values

    return df_imputed

# Example usage
if __name__ == "__main__":
    # Creating a sample DataFrame with missing values
    data = {
        'A': [1, 2, np.nan, 4],
        'B': [np.nan, 2, 3, 4],
        'C': [1, 2, 3, 4]
    }
    df = pd.DataFrame(data)

    print("Original DataFrame:")
    print(df)

    df_imputed = impute_missing_values_with_mean(df)

    print("\nDataFrame after imputing missing values with mean:")
    print(df_imputed)
```

### Explanation:
- The function `impute_missing_values_with_mean` takes a Pandas DataFrame as input and checks if it's a valid DataFrame.
- It creates a copy of the DataFrame to avoid modifying the original data.
- The function iterates through each column, checking for missing values with `isnull()`, and if found, calculates the mean of the column and fills the missing values using `fillna()`.
- An example usage is provided demonstrating how to create a DataFrame with missing values, apply the imputation function, and print both the original and imputed DataFrames.
