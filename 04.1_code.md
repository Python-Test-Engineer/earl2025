**Imputing Missing Values in a Pandas DataFrame with the Mean of the Column**
====================================================================

Below is a Python implementation that imputes missing values in a Pandas DataFrame with the mean of the column.

```python
# Import necessary libraries
import pandas as pd
import numpy as np

def impute_missing_values(df):
    """
    Imputes missing values in a Pandas DataFrame with the mean of the column.

    Args:
        df (pd.DataFrame): Input DataFrame.

    Returns:
        pd.DataFrame: DataFrame with missing values imputed.
    """
    # Create a copy of the input DataFrame to avoid modifying it in-place
    imputed_df = df.copy()

    # Iterate over each column in the DataFrame
    for column in imputed_df.columns:
        # Check if the column contains any missing values
        if imputed_df[column].isnull().any():
            # Calculate the mean of the column, excluding missing values
            column_mean = imputed_df[column].mean()

            # Replace missing values in the column with the calculated mean
            imputed_df[column] = imputed_df[column].fillna(column_mean)

    return imputed_df

# Example usage:
if __name__ == "__main__":
    # Create a sample DataFrame with missing values
    data = {
        'A': [1, 2, np.nan, 4, 5],
        'B': [np.nan, 2, 3, 4, 5],
        'C': [1, 2, 3, np.nan, 5]
    }
    df = pd.DataFrame(data)

    print("Original DataFrame:")
    print(df)

    # Impute missing values in the DataFrame
    imputed_df = impute_missing_values(df)

    print("\nDataFrame with missing values imputed:")
    print(imputed_df)
```

**Explanation:**

*   The `impute_missing_values` function takes a Pandas DataFrame as input and returns a new DataFrame with missing values imputed.
*   It iterates over each column in the input DataFrame and checks for missing values using the `isnull()` method.
*   If a column contains missing values, it calculates the mean of the column using the `mean()` method, excluding missing values.
*   It then replaces missing values in the column with the calculated mean using the `fillna()` method.
*   Finally, it returns the DataFrame with missing values imputed.

**Note:** This implementation assumes that the DataFrame contains only numeric columns. If the DataFrame contains non-numeric columns, you may need to modify the implementation accordingly.

**Example Use Case:**

*   The example usage demonstrates how to create a sample DataFrame with missing values and impute them using the `impute_missing_values` function.
*   The output shows the original DataFrame with missing values and the DataFrame with missing values imputed.
