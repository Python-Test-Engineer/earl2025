```python
import pandas as pd
import numpy as np

def impute_missing_values_with_mean(df):
    """
    Impute missing values in a DataFrame with the mean of each column.

    Parameters:
    df (pd.DataFrame): The DataFrame with potentially missing values.

    Returns:
    pd.DataFrame: A DataFrame with missing values imputed using column means.
    """
    
    # Ensure that we are only dealing with numerical columns for mean imputation
    numeric_columns = df.select_dtypes(include=[np.number]).columns
    
    # Impute missing values with the mean for each numeric column
    for column in numeric_columns:
        mean_value = df[column].mean()
        df[column].fillna(mean_value, inplace=True)
    
    return df

# Example usage
if __name__ == "__main__":
    # Creating a sample DataFrame with missing values
    data = {
        'A': [1, 2, np.nan, 4],
        'B': [np.nan, 5, 6, 7],
        'C': ['a', 'b', 'c', 'd']  # C is a non-numeric column
    }
    df = pd.DataFrame(data)

    print("Original DataFrame:")
    print(df)

    imputed_df = impute_missing_values_with_mean(df)
    
    print("\nDataFrame after imputation:")
    print(imputed_df)
```

### Explanation:
- The function `impute_missing_values_with_mean` takes a Pandas DataFrame as input.
- It identifies numeric columns where the mean can be calculated.
- It iterates through these columns, calculating the mean for each column and using `fillna` to replace missing values.
- The code includes an example demonstrating how to use this function with a sample DataFrame.
